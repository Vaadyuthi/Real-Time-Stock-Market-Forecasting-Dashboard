# Real-Time-Stock-Market-Forecasting-Dashboard


An interactive web dashboard built with **Streamlit**, **yFinance**, **Plotly**, and **Facebook Prophet**. This application enables users to track real-time stock prices, view company profile overviews, analyze historical market trends with moving averages, and predict future asset prices up to 5 years ahead using time-series machine learning.

---

## Features

* **Real-Time Watchlist:** Live price snapshot cards for major tech and market movers.
* **Interactive Historical Analysis:** Plotly time-series charts with integrated **20-Day** and **50-Day Simple Moving Averages (SMA)** and price range sliders.
* **AI Price Forecasting:** Powered by **Facebook Prophet** to forecast future prices up to 5 years into the future, along with trend and seasonal decomposition charts.
* **Universal Ticker Support:** Select from popular preset stocks/ETFs/crypto or type in *any* custom Yahoo Finance ticker globally.

---

## 🛠️ Tech Stack

* **Frontend & UI:** [Streamlit](https://streamlit.io/)
* **Data Retrieval:** [yfinance](https://pypi.org/project/yfinance/)
* **Visualization:** [Plotly](https://plotly.com/), [Matplotlib](https://matplotlib.org/)
* **Machine Learning / Forecasting:** [Prophet](https://facebook.github.io/prophet/)
* **Data Processing:** [Pandas](https://pandas.pydata.org/)
